# SENN TOOLS — Final Build

A browser-based creative utility suite. Open `index.html` directly or publish the folder using GitHub Pages.

## Included
- Image Studio with live Before / After comparison.
- Live brightness, contrast, saturation, exposure, temperature, tint, sharpness, blur, and vignette controls.
- Mono, sepia, vintage, cool, and warm effects.
- Rotate, flip, resize, PNG/JPEG/WebP export.
- Standalone image converter and compressor.
- QR generator, text toolkit, color picker, and unit converter.
- TikTok / YouTube link detection and official-platform handoff.

## Important notes
- Image editing, conversion, and compression run locally in the browser using Canvas.
- QR generation loads an external QR service and therefore needs an internet connection.
- Google Fonts are optional; the page falls back to system sans-serif fonts.
- Media Links does not scrape media, remove watermarks, or bypass platform protections. Use official platform features for content you own or are authorized to use.
- No AI image generation/upscaling is advertised as functional. Real AI inference requires a model or backend integration.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select the `main` branch and `/ (root)`, then save.
