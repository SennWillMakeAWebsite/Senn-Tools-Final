Basic adjustments

Atur tampilan foto. Preview ringan diperbarui saat slider digeser.

Pelajari fungsi pengaturan

Brightness mengatur terang keseluruhan. Contrast menguatkan perbedaan area terang dan gelap. Saturation mengatur kuat warna. Exposure mengatur pencahayaan. Temperature membuat warna lebih hangat atau dingin. Tint menggeser warna ke hijau atau magenta. Sharpness menegaskan detail. Blur melembutkan gambar.

Transform image

Ubah arah, ukuran, dan area gambar.

Cara menggunakan Transform

Rotate memutar 90°. Flip mencerminkan gambar. Isi Width dan Height untuk mengubah ukuran. Keep aspect ratio menjaga proporsi. Crop memakai koordinat X/Y dan ukuran area dalam piksel gambar asli.

Crop area Set the source image rectangle in pixels

Creative effects

Pilih preset warna, lalu sesuaikan hasilnya di Adjust.

Penjelasan preset efek

Original tanpa preset. Mono hitam putih. Sepia nuansa cokelat klasik. Vintage tampilan retro. Cool warna lebih dingin. Warm warna lebih hangat. Vignette menggelapkan tepi foto.

Export settings

Unduh hasil edit resolusi penuh, bukan preview kecil.

Format mana yang harus dipilih?

PNG cocok untuk grafis dan transparansi. JPEG cocok untuk foto dengan ukuran lebih kecil. WebP biasanya memberi ukuran efisien dengan kualitas baik. Quality mengatur kompresi JPEG/WebP; PNG tidak memakai pengaturan kualitas seperti keduanya.

Image format converter

Ubah format file gambar tanpa mengubah dimensi aslinya.

Cara menggunakan

Pilih gambar, tentukan format tujuan, atur Quality untuk JPEG/WebP, lalu tekan Convert & download. PNG cocok untuk transparansi; JPEG/WebP biasanya lebih ringan untuk foto.

▧

Image compressor

Kecilkan ukuran file dengan mengatur format dan kualitas kompresi.

Cara menggunakan

Pilih foto, pilih WebP atau JPEG, turunkan Quality untuk file lebih kecil, lalu tekan Compress & download. Kompresi lebih kuat dapat mengurangi detail. PNG bersifat lossless dan belum tentu lebih kecil.
